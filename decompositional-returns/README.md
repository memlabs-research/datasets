# Decompositional returns

Daily Hyperliquid candle snapshots for the decompositional returns notebook. Only completed candles are included. See manifest.json for the download time, available ranges and row counts. API history availability varies by coin.

Columns: t (open time, Unix milliseconds UTC), T (close time, Unix milliseconds UTC), s (coin), i (interval), o/h/l/c (OHLC prices), v (volume), n (trade count).
